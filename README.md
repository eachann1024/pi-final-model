# pi-final-model

让 Pi 用工作模型执行任务，再由指定模型整理最终答复，完成后恢复工作模型、思考强度和工具。

## 安装与设置

要求 Node.js 22.19+、Pi 1.2.0。

```bash
pi install /path/to/pi-final-model
```

已有会话执行 `/reload`。首次在交互式 Pi 中加载时自动打开设置网页；以后只有一个入口：

```text
/final-model    设置
```

在页面中搜索并选择最终答复模型，打开“使用独立的最终答复模型”即可；改动自动保存，当前会话立即读取新配置。其他已打开会话在下次普通任务开始时读取。新安装默认关闭，原有配置升级后保留。

页面采用单列设置面板、颗粒云雾背景与带白边的磨砂玻璃标识，使用系统字体。背景和图标随插件分发，不加载第三方脚本、字体或图片。

- 只列出已登记、已配置认证的具体模型；排除 Magpie `group/` 路由组和 Pi 虚拟模型。列表为空时，先在 Pi 登记模型和认证，再重新打开设置。
- 模型列表与“执行任务”模型均读取当前 Pi 会话，可见页面每 5 秒刷新；保存中、未保存修改或连接失败时暂停刷新，避免覆盖操作。模型选择器支持搜索、键盘选择、Escape 收起和保存失败重试；恢复失败时提供“恢复整理状态”。任务执行期间允许查看，保存需等任务结束。
- 设置页只监听本机随机端口；刷新页面保留当前标签的访问凭据。连续 30 分钟没有有效设置请求、Pi 退出、重载或切换会话后链接失效，可从设置入口重新打开。
- 首次自动打开仅限 TUI；RPC、SDK 的非 TUI 模式、JSON、print 和子代理不会弹出浏览器。系统无法自动打开时在 Pi 内提供链接，并在下次交互式加载时重试。
- 0.2.0 起移除 `status / set / on / off / recover` 子命令及两个专用 CLI 参数，统一在设置页操作。

配置存于 `~/.pi/agent/final-model.json`，遵循 `PI_CODING_AGENT_DIR`；插件不修改模型目录、认证或全局工作模型。`settingsOpened` 记录是否已成功启动过设置页，旧配置无需手动迁移：

```json
{
  "enabled": true,
  "model": "magpie-groups/codex/gpt-6-luna",
  "settingsOpened": true
}
```

## 执行过程

1. 当前模型照常处理用户任务，工具调用、重试、压缩和排队消息由 Pi 管理。
2. 任务正常完成后，插件在同一轮次内直接调用最终模型，不向会话新增用户消息，也不切换工作模型；整理请求移除历史工具声明，保留工具调用与结果，并在请求末尾明确要求重写答复。
3. 最终模型根据原始需求、执行过程和工具结果整理文本；成功后通过 Pi 的上下文编辑替换原助手答复内容。失败、中断或上下文不足时保留原答复。

已处理的助手消息记录存在当前会话分支，不发送给模型。重载、续接和树导航会读取该记录，避免重复整理。

`pi-subagents` 子会话保留自己的模型和输出约定，本插件在 `PI_SUBAGENT_CHILD=1` 时不注册任何能力。

## 行为边界

- 用户只看到一条最终助手答复；原模型的草稿内容被上下文编辑替换，不另起一条用户或助手消息。会话记录仍显示该答复由工作模型产生。
- 每个正常用户轮次最多整理一次。A 报错、中断、输出截断、无助手答复或工具终止时不整理；其他扩展 custom message 单独启动的轮次也不触发。
- B 未登记、认证未配置、上下文容量不确定或不足时保留 A 的答复。插件不丢弃工具证据，可先压缩上下文或换更大模型；容量仍以服务端实际限制为准。
- B 错误或中断后不再次自动整理；网络重试沿用 Pi 设置。
- 自定义网关别名需要用户确保直达具体模型。其他扩展改写模型、上下文或拦截 `[[FINAL]]` 可能影响最终整理。
- 在已核对的 Pi 1.2.0 中，`agent_settled` 后发送的消息延后处理，A 与 B 各发出一次 settled；RPC/SDK 消费者应检查最后助手模型或等待完整 prompt/idle。

## 诊断日志

日志默认写入 `~/.pi/agent/logs/final-model.jsonl`，遵循 `PI_CODING_AGENT_DIR`。每次整理记录请求编号、会话与原答复编号、模型、耗时、结束原因、服务端响应编号、用量及返回内容的类型和长度；失败通知包含日志位置与请求编号，成功后清除设置页的旧错误。

不记录提示词、答复正文、思考正文或工具参数；错误摘要截断并遮蔽常见凭据格式。日志文件以 `0600` 权限创建，达到 5 MiB 后轮转至 `.jsonl.1`，只保留一份旧文件。日志写入失败会在 stderr 提示，不阻断原答复。开始记录后没有对应响应记录，可能表示进程在请求期间退出。

## 开发与卸载

```bash
npm install --ignore-scripts
npm run check
npm run pack:check
pi remove /path/to/pi-final-model
```

`check` 检查 TypeScript 与前端脚本语法，不运行测试用例。卸载时建议保持空闲、恢复工作模型；配置文件保留。
